# Public technical edition

Repository: [1121eason/UQx2032BrisbaneOlympics-LegacyDB](https://github.com/1121eason/UQx2032BrisbaneOlympics-LegacyDB).

This repository contains the executable database project, a deliberately altered demonstration dataset, historical model structures, query documentation and validation tools. It does not contain the original report, team charter, unmodified database backup or raw source workbook.

Known identity/contact fields are replaced in the public data: person names and dates of birth, medical registration numbers, and supplier/contractor names and emails. Model author metadata is replaced with the team name. The private source archive remains separate.

Keep future additions within the same public scope. Review new source files for student identifiers, private contact details and raw medical records before publication.

The work remains attributed to its original team. No official university/Olympic affiliation or new redistribution licence is implied by the repository name.
